# 헬스장 업무 대시보드

다지점 헬스장의 **회원 · 매출 · 상담 · PT를 한 곳에서 입력하고 보는** 웹 대시보드.

```bash
cd web && npm install && npm run dev
```

Supabase 설정 없이도 데모 데이터로 전체 화면이 돕니다 → http://localhost:5173

## 구성

```
supabase/
  migrations/   스키마 (표·조회식·권한)
  seed.sql      지점·상품·유입경로 초기값
  tests/        업무 시나리오 검증 22건
  run-tests.sh  로컬 PostgreSQL로 전부 검증
web/
  src/pages/    홈 · 회원 · 신규등록 · 재등록관리 · 상담
  src/data/     Supabase / 데모 두 가지 데이터 소스
```

## 기술

- **React + Vite + TypeScript + Tailwind**
- **Supabase** (PostgreSQL · 로그인 · 지점별 접근 권한)
- **Cloudflare Pages** 배포 — 무료 플랜이 상업적 이용을 허용하기 때문
  (Vercel Hobby는 비상업적 용도 전용이라 사업 운영에는 부적합)

## 설계에서 중요한 것들

- **계약과 결제를 분리한다.** 분할결제 시 월매출이 결제 시점 기준으로 갈린다.
- **환불은 지우지 않고 음수로 남긴다.** 과거 매출이 소급 변경되지 않고 분쟁 근거가 남는다.
- **만료일을 둘 저장한다.** 정지(홀딩)가 여러 번 들어오거나 취소돼도 계산이 어긋나지 않는다.
- **잔여 세션은 저장하지 않고 계산한다.** 이중 저장은 반드시 어긋난다.
- **지점 격리는 DB(RLS)가 강제한다.** 앱 코드가 실수해도 타 지점 데이터가 나가지 않는다.
- **진행 중인 달은 전월 같은 기간과 비교한다.** 아니면 월말까지 늘 마이너스로 보인다.
