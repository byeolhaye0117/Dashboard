## 3. 상품 — 가장 중요한 발견 5가지

### ① "1+2개월" 구조 — 결제 기간 ≠ 이용 기간

거의 모든 회원권이 `결제 개월 + 서비스 개월` 형태입니다.

| 상품 | 결제 | 서비스 | **실제 이용** |
|---|---|---|---|
| 지역주민 1+2개월 | 1개월 | 2개월 | **3개월** |
| 하루특가 2+3개월 | 2개월 | 3개월 | **5개월** |
| 지역주민 2+5개월 | 2개월 | 5개월 | **7개월** |
| 프리미엄 6+6개월 | 6개월 | 6개월 | **12개월** |
| 오픈특가 1+2개월 | 1개월 | 2개월 | **3개월** |
| 오픈특가 3+3개월 | 3개월 | 3개월 | **6개월** |
| 오픈특가 4+8개월 | 4개월 | 8개월 | **12개월** |
| 재등록 스탠다드 1+2 | 1개월 | 2개월 | **3개월** |
| 재등록 스탠다드 3+9 | 3개월 | 9개월 | **12개월** |
| 재등록 프리미엄 1+2 | 1개월 | 2개월 | **3개월** |
| 재등록 프리미엄 3+9 | 3개월 | 9개월 | **12개월** |

**설계 반영:** 상품에 `결제 개월`과 `서비스 개월`을 따로 저장한다.
**만료일 = 시작일 + (결제 개월 + 서비스 개월)** 로 자동 계산한다.
이걸 하나로 합쳐두면 만료일이 틀리고, 만료 임박 알림 전체가 무용지물이 된다.

### ② 현금가 / 카드가 2중 가격

모든 상품에 현금(계좌)가와 카드가가 따로 있고, 카드가는 대체로 현금가 + 10%입니다.

**설계 반영:** 상품에 두 가격을 다 저장한다.
결제 등록 화면에서 결제 수단을 고르면 해당 가격이 자동으로 채워지고, 수정도 가능하게 한다.

❓ **확인 필요:** 매출 집계를 **실제 받은 금액**(카드면 카드가)으로 잡으면 되나요?
아니면 부가세를 뺀 금액으로 따로 봐야 하나요?

### ③ 재등록 전용 상품이 따로 있음 — 재등록률 계산이 쉬워짐

`재등록 스탠다드`, `재등록 프리미엄` 상품이 별도로 존재합니다.

**설계 반영:** 상품에 `신규용 / 재등록용` 구분을 넣으면,
직원이 따로 표시하지 않아도 **재등록률이 자동 계산**된다.

### ④ 서비스 상품 18종 — 무료로 딸려가는 항목

`완초자 PT 10회 서비스`, `사물함 서비스`, `24시 서비스` 등은 가격이 없습니다.
회원권을 팔면서 얹어주는 항목으로 보입니다.

❓ **확인 필요 (중요):**
- 서비스 상품은 **어떤 회원권을 사면 자동으로 따라오나요?** 아니면 **직원이 협상해서 골라 얹어주나요?**
- 서비스로 받은 `완초자 PT 10회`도 **횟수를 차감 관리**해야 하나요?
- 서비스가 회원권보다 값어치가 클 수 있는데(예: 완초자 PT 30회), **얼마어치를 서비스로 줬는지 집계**하고 싶으신가요?
  → 원하시면 "서비스 원가"를 넣어서 **지점별·직원별 서비스 남발 정도**를 볼 수 있습니다.

### ⑤ 특수 상품 3개 — 별도 처리가 필요합니다

| 상품 | 문제 | 확인 필요 |
|---|---|---|
| **1:1PT 75회 (3인나눔)** | 회원 3명이 나눠 쓰는 상품. 회원 1명에 붙일 수 없음 | 3명을 묶는 구조가 필요한가요? 아니면 대표 1명에게 달아두시나요? |
| **24시 75% 할인 / 여성전용 75% 할인** (5,000원) | 상품이라기보다 **추가 옵션 요금**으로 보임 | 회원권에 붙는 옵션인가요, 단독 판매인가요? |
| **프로틴** (120,000원) | 물품 판매. 회원권이 아님 | 재고 관리도 필요하신가요? |
