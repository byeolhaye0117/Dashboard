# 헬스장 통합 업무 대시보드 — 기획서

- 문서 버전: v0.1 (초안)
- 최종 수정: 2026-07-29
- 상태: **검토 중 (확정 아님)**

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 여러 지점의 헬스장 업무를 한 화면에서 관리 |
| 사용자 | 대표 + 지점장 + 직원 (트레이너 / 데스크) |
| 직원 규모 | 10~30명 |
| 지점 규모 | 4개 이상 |
| 기기 | PC / 태블릿 / 휴대폰 (하나의 주소, 화면 크기에 따라 배치 자동 조정) |
| 권한 | 직급으로 기본값 부여 + 개인별 예외 조정 |
| 기존 시스템 | 브로제이(BROJ) CRM 사용 중 |
| 배포 | GitHub + Vercel |

## 2. 기존 시스템(브로제이)과의 역할 분담

브로제이가 이미 제공하는 기능:

- 회원 관리 (일반 / PT 구분)
- 지점별 매출 통계 및 순위
- 미수금 고객 관리 및 추출
- 종목 / 상품 / 태그별 조회 및 **엑셀 추출**
- 카드 단말기 연동
- 출입제어 키오스크 (얼굴인식)
- 전자계약서, 자동문자 / 푸시

**따라서 대시보드는 브로제이를 대체하지 않는다.** 브로제이가 다루지 않는 영역을 채우고,
브로제이 데이터를 가져와 다른 데이터와 엮어서 새로운 정보를 만든다.

| 업무 | 원본 | 대시보드 역할 |
|---|---|---|
| 회원 명단 / 이용권 | 브로제이 | 읽어와서 표시 · 분석 |
| 결제 / 매출 | 브로제이 | 읽어와서 표시 · 분석 |
| 회원 출입 기록 | 브로제이 | 읽어와서 이탈 위험 분석 |
| 직원 근태 (위치확인) | **대시보드** | 원본 |
| 상담 · 리드 추적 | **대시보드** | 원본 |
| 공지 · 업무 체크리스트 | **대시보드** | 원본 |
| 시설 · 재고 관리 | **대시보드** | 원본 |
| PT 스케줄 | 미정 | 브로제이 확인 필요 |

## 3. 권한 구조

### 3-1. 2단계 구조

1. **직급(Role)** — 대표 / 지점장 / 트레이너 / 데스크 등. 직급마다 기본 권한 세트를 정의
2. **개인 예외** — 특정 직원만 추가로 켜거나 끄기

직원 10~30명 규모에서는 사람마다 일일이 설정하면 관리가 안 되므로 직급 기반이 필수다.

### 3-2. 지점 범위

권한은 "무엇을 보는가"와 "어느 지점을 보는가" 두 축으로 나뉜다.

| 범위 | 설명 |
|---|---|
| 전체 | 모든 지점. 지점 합산 + 지점 간 비교 |
| 지정 지점 | 배정된 지점만 (복수 가능) |
| 본인 소속 지점 | 소속된 한 지점만 |

### 3-3. 권한 종류

각 메뉴마다 다음 4가지를 따로 켜고 끈다.

| 권한 | 설명 |
|---|---|
| 보기 | 메뉴가 보이고 목록을 열람할 수 있음 |
| 등록 | 새 항목을 추가할 수 있음 |
| 수정 | 기존 항목을 고칠 수 있음 |
| 삭제 | 항목을 지울 수 있음 |

권한이 없는 메뉴는 화면에 아예 나타나지 않는다. (주소를 직접 입력해도 차단)

## 4. 화면 구성

### 4-1. 공통 뼈대

```
┌────────────────────────────────────┐
│  로고   [지점 선택▼]      김트레이너 ▼│  ← 상단 바
├──────┬─────────────────────────────┤
│ 메뉴 │                             │
│ 홈   │      선택한 메뉴의 내용       │
│ 회원 │                             │
│ 매출 │   (권한 있는 메뉴만 왼쪽에)   │
│ 근태 │                             │
└──────┴─────────────────────────────┘
```

| 기기 | 배치 |
|---|---|
| PC (1024px 이상) | 왼쪽 메뉴 고정 + 넓은 표 |
| 태블릿 (768~1024px) | 왼쪽 메뉴 아이콘만, 표 열 축소 |
| 휴대폰 (768px 미만) | 아래쪽 탭바, 표는 카드 형태로 전환 |

### 4-2. 홈 화면 (역할별)

**대표 홈**
- 전 지점 오늘 매출 / 이번 달 누적 / 목표 대비 달성률
- 지점별 매출 순위
- 이번 달 만료 예정 회원 수, 재등록률
- 신규 상담 → 등록 전환율
- 미처리 상담 건수 (지점별)

**지점장 홈**
- 자기 지점 오늘 매출 / 신규 등록 / 출석 인원
- 직원 출근 현황 (지각 · 미출근)
- 오늘 처리할 일 (만료 임박 회원 연락, 미처리 상담)
- 재고 부족 알림

**트레이너 홈**
- 오늘 내 PT 스케줄
- 내 담당 회원 중 최근 미출석자
- 내 이번 달 수업 건수 / 재등록 현황
- 나에게 배정된 업무 체크리스트

**데스크 홈**
- 오늘 상담 예약
- 만료 임박 회원 연락 목록
- 오늘 업무 체크리스트

## 6. 운영 지표 (대시보드만의 부가가치)

### A. 매출 방어 지표 — 우선순위 높음

| 지표 | 정의 | 활용 |
|---|---|---|
| 이탈 위험 회원 | 유효 회원 중 최근 N일 출석 0회 | 연락 대상 목록 자동 생성 |
| 만료 임박 | 이용권 종료일 기준 D-30 / D-14 / D-7 | 단계별 연락 타이밍 관리 |
| 재등록률 | 만료자 중 재등록한 비율 (지점별 / 월별) | 지점 운영 평가 |
| 미수금 | 분납 미납, 결제 실패 건 | 회수 관리 |

### B. 직원 평가 지표

| 지표 | 정의 |
|---|---|
| 상담 전환율 | 담당 상담 건수 대비 등록 성사 비율 |
| 트레이너 재등록률 | 담당 PT 회원의 연장 비율 |
| 직원별 매출 기여도 | 담당자로 기록된 결제 합계 |

### C. 운영 조정 지표

| 지표 | 정의 |
|---|---|
| 시간대별 혼잡도 | 회원 출입 기록의 시간대 분포 |
| 객단가 | 회원 1인당 평균 결제액 (지점 비교) |
| 평균 유지 기간 | 최초 등록일 ~ 최종 만료일 평균 |

## 7. 개발 단계

| 단계 | 내용 | 완료 시 확인 가능한 것 |
|---|---|---|
| 0 | 데이터 구조 확정 | 무엇을 저장할지 문서로 합의 |
| 1 | 로그인 + 권한 + 화면 뼈대 | 사람마다 다른 메뉴가 보임 |
| 2 | 첫 업무 모듈 | 실제 업무에 사용 시작 |
| 3 | 모듈 순차 추가 | 써보면서 하나씩 |
| 4 | 브로제이 데이터 연동 | 회원·매출 자동 반영 |
| 5 | 운영 지표 · 그래프 | 데이터 축적 후 |
