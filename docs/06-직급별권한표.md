## ❗ 이 표는 "고정값"이 아닙니다

**권한은 대표님이 화면에서 직접 설정합니다.** (2026-07-29 확정)

- 이 표는 처음 시스템을 깔 때 들어가는 **기본값**일 뿐입니다.
- 대시보드에 **권한 설정 화면**을 만들어서, 직급마다 메뉴별 체크박스를 켜고 끌 수 있게 합니다.
- 바꾸면 해당 직급 직원들에게 **바로 적용**됩니다. 제가 코드를 고칠 필요가 없습니다.
- 특정 직원 한 명만 예외로 열어주는 것도 화면에서 가능합니다.

즉 아래 표가 마음에 안 드셔도 괜찮습니다. 나중에 화면에서 바꾸시면 됩니다.

## 읽는 법

| 표시 | 뜻 |
|---|---|
| **전권** | 보기 + 등록 + 수정 + 삭제 전부 가능 |
| **등록** | 보기 + 새로 등록까지 가능. 수정·삭제는 불가 |
| **보기** | 목록과 내용을 볼 수만 있음 |
| **본인** | 자기 것만 보임 (예: 자기 근태만) |
| **담당** | 자기가 담당하는 회원 것만 보임 |
| ❌ | 메뉴가 아예 안 보임 |

**지점 범위**는 "어느 지점의 데이터를 볼 수 있는가"입니다.
`전체`는 4개 지점 전부, `담당`은 배정된 지점만입니다.

### 확정된 부분 (2026-07-29)

| # | 항목 | 결정 |
|---|---|---|
| 1 | 매니저 | 대표 다음 등급. 전 지점 전권 |
| 2 | PT 총괄 매니저 / PT 팀장 | **PT 매출만** 조회. 전체 매출은 안 보임 |
| 3 | **"PT 매출"의 정의** | **1:1PT 상품만.** 그룹수업(완초자·기구필라테스)은 제외 |
| 4 | 트레이너 | **자기 담당 회원만** 조회 |
| 5 | 스태프 | 회원 등록 + **수정·삭제까지 가능** |
| 6 | 점장의 매출 조회 범위 | **자기 지점만.** 다른 지점 매출은 못 봄 |
| 7 | 근태 승인 (반경 밖) | **대표 또는 매니저** |
| 8 | 휴무 승인 | **대표 또는 매니저** |

> 점장·실장은 근태·휴무를 **볼 수는 있지만 승인은 못 합니다.**
> 승인 권한도 화면에서 켜고 끌 수 있게 만듭니다.
