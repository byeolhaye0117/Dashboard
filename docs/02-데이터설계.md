❗ **가장 중요한 미결정 항목입니다.**
브로제이 키오스크(얼굴인식 출입)와 별개이므로, 대시보드는 회원이 언제 왔는지를 알 방법이 없습니다.

기록 방법 후보:
1. **데스크 태블릿에서 체크** — 회원이 오면 데스크 직원이 이름 검색 후 출석 버튼. 직원 일이 늘어남
2. **회원용 QR 화면** — 입구 태블릿에 QR을 띄우고 회원이 휴대폰으로 스캔. 회원에게 설명이 필요함
3. **회원 전화번호 뒷자리 입력** — 입구 태블릿에 회원이 직접 4자리 입력. 가장 빠르고 직원 부담 없음
4. **기록하지 않음** — 이탈 위험 분석 기능을 포기
